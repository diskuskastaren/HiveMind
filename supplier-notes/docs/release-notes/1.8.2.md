# HiveMind 1.8.2

Fixes for tabs and the sidebar. Your notes, settings and API keys carry over from 1.8.1.

## Fixed

- Tabs in a note stay where they are when you click one. Every tab now has its menu button (▾), shown
  when you point at the tab.
- In the sidebar, pointing at a note no longer makes the row taller or moves the notes below it. Its
  Archive and Delete buttons appear over the row's right edge.

HiveMind is not code-signed. Windows SmartScreen may show "Windows protected your PC" for a new
version; choose **More info → Run anyway**.

Download **HiveMind-Setup-1.8.2.exe** below to install or update the Windows app.
