# HiveMind 1.8.3

A fix for saving. Your notes, settings and API keys carry over from 1.8.2.

## Fixed

- "Could not save data … EPERM: operation not permitted, rename" no longer appears when another
  program (antivirus, the Windows search indexer, a sync or backup tool) briefly has the data file
  open. HiveMind now waits and tries again for up to five seconds before it reports that a save
  failed. The same applies when a backup is finished.

No data was lost by the error: a failed save left the previous file in place, and the next save wrote
everything.

HiveMind is not code-signed. Windows SmartScreen may show "Windows protected your PC" for a new
version; choose **More info → Run anyway**.

Download **HiveMind-Setup-1.8.3.exe** below to install or update the Windows app.
