# HiveMind 1.8.3

Fixes for saving and for error messages. Your notes, settings and API keys carry over from 1.8.2.

## Fixed

- "Could not save data … EPERM: operation not permitted, rename" no longer appears when another
  program (antivirus, the Windows search indexer, a sync or backup tool) briefly has the data file
  open. HiveMind now waits and tries again for up to five seconds before it reports that a save
  failed. The same applies when a backup is finished.

- Error and warning messages in the bottom-right corner now have a close button (×), so you can
  dismiss them. Before, messages that stay until dismissed could not be clicked away.
- A save that fails several times shows one "Could not save data" message instead of one for each
  attempt, and the message disappears by itself when the next save works.

No data was lost by the save error: a failed save left the previous file in place, and the next save wrote
everything.

HiveMind is not code-signed. Windows SmartScreen may show "Windows protected your PC" for a new
version; choose **More info → Run anyway**.

Download **HiveMind-Setup-1.8.3.exe** below to install or update the Windows app.
