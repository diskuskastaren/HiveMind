# HiveMind 1.8.0

Tabs inside meeting notes. Your notes, settings and API keys carry over from 1.7.0; data stays in the
same Windows profile, and existing notes are not changed.

## Tabs in a note

When one meeting covers several sub-projects or topics, split the note into named tabs instead of
writing one long document or several notes.

- Click the dashed **+ Tab** chip under the note's title, or type **/new tab** in the text. The note's
  current text becomes the first tab, unchanged.
- Each tab has its own text and its own undo history.
- Double-click a tab to rename it. Drag a tab, or use its menu (▾ or right-click), to move it.
- Switch tabs with a click, the arrow keys, or **Ctrl+PageDown** / **Ctrl+PageUp**.
- Deleting a tab can be undone from the notice that appears. Removing all but one tab makes it a plain
  note again.
- A note with one tab looks exactly as before. In the sidebar, notes with tabs show how many they have.

## Works with the rest of HiveMind

- Search, the Markdown and email exports, and AI features read every tab; each tab becomes a heading
  in the Markdown export.
- **Add to note** and **Insert into note** in the transcript panel add the summary or transcript to the
  tab being shown. The new **As tab** buttons add it as a tab of its own.
- Tasks, decisions, transcripts and attachments still belong to the whole note.
- Find & replace (Ctrl+F) works in the tab being shown.

HiveMind is not code-signed. Windows SmartScreen may show "Windows protected your PC" for a new
version; choose **More info → Run anyway**.

Download **HiveMind-Setup-1.8.0.exe** below to install or update the Windows app.
