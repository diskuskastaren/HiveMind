# HiveMind 1.8.1

A fix for the tabs in meeting notes. Your notes, settings and API keys carry over from 1.8.0.

## Fixed

- In a narrow window, the tab bar of a note no longer shows scrollbars, also not while the pointer is
  over a tab.
- When a note has more tabs than fit, the edges of the tab bar fade to show that there are more. Scroll
  the bar with the mouse wheel, or open the list button next to **+** to jump to any tab.
- Hovering a tab no longer makes the tab bar jump.

HiveMind is not code-signed. Windows SmartScreen may show "Windows protected your PC" for a new
version; choose **More info → Run anyway**.

Download **HiveMind-Setup-1.8.1.exe** below to install or update the Windows app.
