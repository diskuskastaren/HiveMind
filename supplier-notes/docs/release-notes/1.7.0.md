# HiveMind 1.7.0

A reliability, privacy and security release. Your notes, settings and API keys carry over from 1.6.0;
data stays in the same Windows profile.

## Your data is safer

- Undo right after opening another note no longer copies the previous note's text into it.
- Edits made just before closing HiveMind are saved, and a slow start can no longer save an empty
  workspace over your data.
- Notes are saved even when the Windows key store is unavailable. If an API key cannot be stored, you
  are told, and it is stored with your next change.
- Importing a backup asks first and makes a backup of your current data before replacing it.
- The task dialog keeps your unsaved edits when you flag a task, link a follow-up or attach a file.
- Backups take far less disk space: images and attachments that have not changed are shared between
  backups instead of being copied every time.
- Collapsible sections keep their title and open or closed state; content in sections created with
  earlier versions is visible again.

## Meetings and AI

- Summaries follow your own instructions and are written in the transcript's language. Headings and
  lists now show correctly in the side panel, the note and Outlook drafts.
- New setting: **Summarize recordings automatically**. Turn it off for confidential meetings and
  summarize only when you choose.
- Import a Teams transcript (.vtt, .srt or text) without recording.
- Recording: failed transcription uploads are retried, the last part of a recording is kept when you
  stop, and problems are shown instead of failing silently.
- The level visualizer is drawn correctly on scaled displays (125–150 %) and keeps updating while
  recording system audio.
- Help → Privacy explains exactly what is sent to OpenAI and Groq, and when.

## Tasks, follow-ups and decisions

- Follow-ups can be edited in the side panel and on the board.
- Linked tasks and follow-ups stay in sync on both sides.
- Revoked or replaced decisions move to their own list, with Undo; decision history opens from search.
- Deleting a task or follow-up can be undone.
- Due dates use your local calendar day, so items no longer turn overdue early.
- My Work has an Internal filter.

## Updates and security

- If an update cannot be installed (for example when antivirus software blocks it), HiveMind says so
  and offers a manual download. Update activity is logged in `%APPDATA%\supplier-notes\logs`.
- Opening HiveMind a second time switches to the window that is already open.
- Turning off Teams meeting detection takes effect immediately.
- Text and HTML stored in notes can never run code, and links and attachments only open from safe
  places.
- Built on Electron 45 with an updated editor (TipTap 3), including their security fixes. The installed
  app also takes about 90 MB less disk space.

HiveMind is not code-signed. Windows SmartScreen may show "Windows protected your PC" for a new
version; choose **More info → Run anyway**.

Download **HiveMind-Setup-1.7.0.exe** below to install or update the Windows app.
